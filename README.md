# Pet Management System
 
## Overview
 
The Pet Management System is a Python application developed for ITEC 352: Software Design at the University of South Carolina. The project demonstrates Object-Oriented Programming (OOP) principles by modeling different types of pets using inheritance, polymorphism, and reusable class structures.
 
The application stores information about various pets, including dogs and cats, and generates detailed descriptions based on each pet's characteristics. Users can view pet information and explore how object-oriented design simplifies data organization and program scalability.
 
---
 
## Learning Objectives
 
This project was designed to apply key software design concepts, including:
 
- Object-Oriented Programming (OOP)
- Class Design
- Inheritance
- Polymorphism
- Method Overriding
- Encapsulation
- Data Modeling
- Software Reusability
- Program Testing and Debugging
 
---
 
## Features
 
- Creates and manages pet objects
- Implements a superclass for shared pet attributes
- Uses subclass inheritance for Dog and Cat objects
- Overrides methods to provide pet-specific behavior
- Classifies pets based on age and life stage
- Displays detailed pet information
- Randomly selects pets from a collection
